# SlideForge

Мікро-інструмент: текст → 5–8 слайдів Instagram-каруселі → PNG.

## Що вміє
- Вставив тему / чернетку
- Обрав тон і шаблон (світлий / темний / акцент)
- Отримав 6 слайдів (hook → tips → CTA)
- Завантажив один або всі PNG (1080×1350)
- Ліміт 3 генерації на день (localStorage)

## Як відкрити
Просто відкрий `index.html` у браузері (подвійний клік або Live Server).
Без бекенду і без API-ключів — демо на шаблонах.
