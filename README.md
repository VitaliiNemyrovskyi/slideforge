# SlideForge

Мікро-інструмент: текст → 5–8 слайдів Instagram-каруселі → PNG.

## Що вміє
- Тема / чернетка → 6 слайдів
- 20 фонів у комплекті (градієнти + спокійні фото)
- Темний / світлий текст поверх фону
- PNG 1080×1350 (один або всі)
- Ліміт 3 генерації на день (localStorage)
